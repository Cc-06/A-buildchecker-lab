从源码包或 Git bundle 恢复仓库，按 `复现说明.md` 使用独立目录运行；已有 work 输出应保留，改用新编号。固定环境镜像和源码 SHA 与本轮证据对照；新机器重建环境后的 image ID 可以不同，应重新记录。
